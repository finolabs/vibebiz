# Driver tree (KPI tree)

## When to use
- The user states a wish ("tăng doanh thu", "có chatbot") and the measurable outcome, baseline and target are still open.
- You need to show which number the idea moves, and which numbers it must not hurt.
- The board will ask "con số nào thay đổi và thay đổi bao nhiêu".

## When not to use
- The user has no baseline and no way to get one: first record a measurement plan, then build the tree.
- The idea is a compliance or legal fix with a pass or fail result, not a number.
- The problem itself is still unclear: finish the problem framing first.

## Inputs
- The top outcome in the user's words, with its period.
- Current figures for each branch, with source and period, or a note that they are unknown.

## Questions
Break the top outcome into drivers that multiply or add up to it, two levels is enough. Mark each driver as leading (moves early, for example footfall, conversion) or lagging (arrives late, for example revenue, return rate).
1. "Con số nào bạn muốn cải thiện nhất nếu ý tưởng này thành công?" Offer two to four candidates from the fashion pack: "Tỷ lệ mua hàng trên lượt vào cửa hàng (Đề xuất)", "Giá trị trung bình mỗi đơn", "Tỷ lệ trả hàng".
2. "Hiện giờ con số đó là bao nhiêu, lấy từ báo cáo nào, của giai đoạn nào?" (a fact to look up first; ask only if no file has it)
3. "Ý tưởng này tác động vào nhánh nào của con số đó?" Show the tree and let the user choose the branch.
4. "Con số nào không được xấu đi khi làm việc này?" This becomes the guardrail.
5. Target and time frame as ranges; label any figure you supply as an estimate. Ask for the point at which the idea should be stopped.

## Writes to
- The outcome and success-criteria sections: baseline, target, period, guardrail and stop condition, each with source and a measured or assumed label.
- The completion-signals category: the testable condition derived from the target.
- A diagram brief (type tree) for the board slide on the outcome.

## Common misuse
- Using drivers that do not multiply or add to the top number, so the tree looks tidy but computes nothing.
- Counting an output ("gửi 5.000 tin nhắn") as an outcome.
- Picking a target without a baseline; record the gap as not yet clarified.
- Letting the idea claim the whole top number when it moves only one branch.

## Fashion example (fictional)
Chuỗi Lụa Xanh: store revenue = footfall x conversion x units per transaction x average selling price. A fitting-room queue idea moves conversion only. Baseline: conversion 18% (POS report, Q3, measured); target 20% in 3 months in pilot stores (assumed, not tech-reviewed); guardrail: units per transaction does not fall below 1.9; stop if conversion is below 18% after 8 weeks.
