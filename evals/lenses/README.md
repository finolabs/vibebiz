# Lens and depth cases (user story 2)

Cases for suites 3 and 10 from the lens modules: outcome without baseline, AI fit record, first journey that stands alone, and the four Cynefin depths (clear, complicated, complex, chaotic). Seeded cases need `--scaffold`; the four Cynefin cases start from an empty folder and run `new`. No threshold of their own: they count as ordinary cases in the suites named in their tags (suite 3 for judgments, suite 10 for framework behavior).
