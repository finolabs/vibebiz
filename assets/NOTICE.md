# vibebiz icon

Copyright (c) 2026 Fioenix. Distributed under the project license (PolyForm Noncommercial 1.0.0, with a separate commercial license).

The owner chose this hand-authored mark on 14/11/2026 from three concepts: a lowercase b whose bowl is a speech bubble, for the interview that turns an idea into a clear brief. The dot inside the bowl is the idea; the tail is the bubble's. Rounded 9–10-unit strokes follow the FINOLABS icon family, with violet (#9750C4) for light surfaces and mint (#7FE2CE) for dark surfaces. Both themes share identical geometry on a transparent 128-unit canvas. No third-party artwork, font, bitmap tracing or image-model output is included.

Editable sources are icon.svg and icon-dark.svg. The two PNG files are transparent 512×512 exports rendered from them with headless Chrome.

## Social preview

`.github/social-preview.json` renders the 1280×640 GitHub social preview with the FINOLABS social-preview template and `icon-dark.svg`. Its input is the README's example idea and its output is an excerpt of the fictional example's `coverage.md` (`examples/000-giu-chan-khach-cu`). GitHub has no API for it: upload the PNG under the repository's Settings, General, Social preview.
