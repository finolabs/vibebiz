# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, by reference. Read the full text at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

The Contributor Covenant is © its authors and licensed under CC BY 4.0. It applies to all project spaces: issues, pull requests, reviews and discussions.

## In short

Be respectful and constructive. No harassment, discrimination, personal attacks, or publishing other people's private information. Disagree with the idea, not the person. Retail leaders and engineers are both welcome here, and a plain-language question is never a bad question.

## Reporting and enforcement

Report unacceptable behavior privately to the repository owner (Fioenix) through GitHub or the contact route listed in `SECURITY.md`. Reports are handled in confidence. The owner may remove comments, reject contributions or block participants, following the enforcement guidelines in the Contributor Covenant 2.1.
